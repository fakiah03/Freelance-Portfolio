# Fakiah's Freelance Portfolio Website

A complete, modern, responsive freelance portfolio website designed with a cute minimalist aesthetic and a kawaii cat identity.

## Features
- **Cute Minimalist Aesthetic**: Soft pastel purple and white theme.
- **Custom Illustrations**: Features a set of adorable kawaii 2D cat illustrations representing different services (Data Entry, Data Cleaning, Web Research).
- **Fully Responsive**: Works on Mobile, Tablet, and Desktop.
- **Vanilla JS & CSS3**: No heavy frameworks. Highly performant.
- **Service & Portfolio Ready**: Beautifully crafted sections for services, before/after data cleaning, portfolio showcase, and work process.
- **Static Site**: Ready to be deployed on Vercel, Netlify, or GitHub Pages.

## File Structure
- `index.html` - Main landing page.
- `portfolio.html` - Dedicated page for all portfolio items.
- `samples.html` - Page for viewable/downloadable samples.
- `assets/css/` - Core styles, responsive queries, and animations.
- `assets/js/` - Vanilla JavaScript logic.
- `assets/images/cats/` - Custom AI-generated kawaii cat illustrations.

## Usage
Simply open `index.html` in any web browser to view the site, or deploy it using any static hosting provider.
